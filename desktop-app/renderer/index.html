设置

账号与积分

登录后使用云端内置模型（DeepSeek / MiniMax），按积分计费：本地引擎免费，云端写码按 token × 模型系数扣积分。积分不足时提示升级。
套餐积分每月重置 · 充值积分永久有效。切换模型时云端模型将自动走账号积分通道。

AI 模型配置

说明：
• DeepSeek：在 platform.deepseek.com 申请 API Key
• 本地 AI 引擎：LabCode 内置 llama.cpp 引擎，到插件市场安装大模型（国内直链下载）即可使用，无需安装任何外部软件
• 配置保存后，AI 智能体将使用真实模型进行对话和工具调用
