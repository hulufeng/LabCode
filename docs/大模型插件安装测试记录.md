## 二、测试内容

### 2.1 模拟插件市场"Qwen2.5-Coder 1.5B（轻量）"安装

执行命令：
```bash
ollama pull qwen2.5-coder:1.5b
```

**执行结果：**

| 指标 | 数值 |
|------|------|
| 模型大小 | 986 MB |
| 下载耗时 | 31.7 秒 |
| 平均速度 | ~33 MB/s |
| 峰值速度 | ~57 MB/s |
| SHA256 校验 | 通过 |
| 安装结果 | success |

**下载过程关键阶段：**
- pulling manifest：约 2 秒
- 拉取主层（29d8c98fa6b0）：985 MB，约 28 秒
- 拉取配置层（66b9ea09bd5b / 1e65450c3067 / 832dd9e00a68）：< 1 秒
- verifying sha256 digest：约 1 秒
- writing manifest：< 1 秒

### 2.2 验证模型安装

```bash
ollama list
```

安装后共 3 个模型：
- qwen2.5-coder:1.5b (986 MB) — 新增
- qwen2.5-coder:7b (4.7 GB)
- qwen3.5:9b (6.6 GB)

### 2.3 清理测试模型

```bash
ollama rm qwen2.5-coder:1.5b
```

结果：deleted 'qwen2.5-coder:1.5b'，恢复到 2 个模型。

## 三、结论

### 3.1 安装流程可行性

✅ **Ollama 模型拉取流程完全可行**，可直接作为 LabCode 大模型插件的核心安装逻辑：

1. **运行时检测**：`system:checkLLMRuntime` IPC handler 检测 Ollama 是否已安装并运行
2. **运行时安装**（如未安装）：下载 OllamaSetup.exe 并静默安装
3. **模型拉取**：执行 `ollama pull <model-name>`，通过 stdout 解析进度百分比和速度
4. **模型注册**：`refreshLocalModelsInSelector()` 自动将本地模型添加到 AI 模型选择器

### 3.2 性能参考

| 模型规格 | 大小 | 预计下载时间（33MB/s） | 最低显存需求 |
|----------|------|----------------------|-------------|
| 1.5B（轻量） | ~1 GB | ~30 秒 | 2 GB |
| 7B（标准） | ~4.7 GB | ~2.5 分钟 | 6 GB |
| 14B（高性能） | ~9 GB | ~5 分钟 | 10 GB+ |

### 3.3 硬件推荐映射（已实现）

| 硬件等级 | 条件 | 推荐模型 |
|----------|------|----------|
| low | 内存 < 8GB 或无 GPU | 1.5B 级 |
| medium | 内存 8-16GB 或 GPU 4-6GB | 7B 级 |
| high | 内存 > 16GB 或 GPU > 6GB | 14B 级 |

### 3.4 注意事项

1. **首次安装 Ollama** 需要管理员权限，插件安装流程需处理 UAC 弹窗
2. **模型拉取进度**需通过子进程 stdout 实时解析并更新 UI 进度条
3. **磁盘空间检查**：安装前需验证可用空间 ≥ 模型大小 × 1.5（预留解压和临时文件）
4. **网络环境**：国内用户可能需要配置镜像源（Ollama 默认从 registry.ollama.ai 拉取）
