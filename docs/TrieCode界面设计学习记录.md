## 一、整体布局结构

TrieCode 采用 **VS Code 风格的五区布局**：

```
┌─────────────────────────────────────────────────────────┐
│  顶部标题栏（Logo + 菜单 + 工具栏 + 用户 + 设置 + 窗口控制） │
├────┬──────────┬──────────────────────────────────────────┤
│    │          │                                          │
│ 活 │  侧栏    │          主编辑区域                      │
│ 动 │ (文件树) │       (AI对话/代码编辑器)                │
│ 栏 │          │                                          │
│    │          │                                          │
├────┴──────────┴──────────────────────────────────────────┤
│  底部状态栏（语言 + 光标位置 + 编码 + 用户账号）            │
└─────────────────────────────────────────────────────────┘
```

## 二、各区域详细设计

### 2.1 顶部标题栏

**高度**：约 40px
**背景色**：白色 (#ffffff)
**底部边框**：1px 浅灰色 (#e5e7eb)

**左侧元素**：
- TrieCode Logo（TC 图标，蓝黑渐变）

- 菜单栏：文件、编辑、视图、帮助（13px，深灰色，hover 时浅灰背景）

## 四、设计规范总结

### 4.1 颜色系统

| 用途 | 颜色值 | 说明 |
|------|--------|------|
| 主色调 | #2563eb | 蓝色，用于按钮、选中状态、链接 |
| 主色调浅 | #dbeafe | 浅蓝色，用于 hover 背景、图标背景 |
| 主色调更浅 | #eff6ff | 更浅蓝色，用于选中行背景 |
| 背景色 | #ffffff | 白色，主背景 |
| 背景灰 | #f9fafb | 浅灰，次要背景 |
| 边框色 | #e5e7eb | 浅灰，边框 |
| 边框深 | #d1d5db | 深灰，输入框边框 |
| 文字主色 | #111827 | 深灰，标题 |
| 文字次色 | #374151 | 中灰，正文 |
| 文字辅助 | #6b7280 | 浅灰，描述、占位符 |
| 文字更浅 | #9ca3af | 更浅灰，禁用状态 |
| 成功色 | #166534 | 深绿，成功文字 |
| 成功背景 | #dcfce7 | 浅绿，成功背景 |
| 错误色 | #dc2626 | 红色，错误文字 |
| 错误背景 | #fee2e2 | 浅红，错误背景 |

## 五、与 LabCode 的差异对比

### 5.1 主题差异

| 项目 | TrieCode | LabCode（当前） | 需要修改 |
|------|----------|-----------------|----------|
| 主题 | 浅色主题（白色背景） | 深色主题（Catppuccin Mocha #1e1e2e） | ✅ 改为浅色主题 |
| 主色调 | 蓝色 #2563eb | 靛蓝 #4f46e5 + 青色 #06b6d4 | ✅ 改为蓝色 #2563eb |
| 状态栏 | 蓝色背景 | 深色背景 | ✅ 改为蓝色背景 |

### 5.2 布局差异

| 项目 | TrieCode | LabCode（当前） | 需要修改 |
|------|----------|-----------------|----------|
| 顶部菜单栏 | 有（文件、编辑、视图、帮助） | 可能没有 | ✅ 添加菜单栏 |
| 欢迎面板 | 侧栏下方有独立欢迎面板 | 可能没有 | ✅ 添加欢迎面板 |
| 快捷指令 | 4个快捷指令按钮（2x2网格） | 可能没有 | ✅ 添加快捷指令 |
| AI 输入框 | 大圆角、底部工具栏、模型选择 | 设计可能不同 | ✅ 对齐设计 |
| 工作空间路径 | 输入框下方显示路径 | 可能没有 | ✅ 添加路径显示 |

### 5.3 组件差异

| 组件 | TrieCode 设计 | LabCode（当前） | 需要修改 |
|------|--------------|-----------------|----------|
| 按钮 | 蓝色填充 + 白色边框两种，圆角 6px | 可能不同 | ✅ 对齐 |
| 输入框 | 白色背景 + 浅灰边框，圆角 6px | 深色背景 | ✅ 改为浅色 |
| 标签切换 | 蓝色/白色，圆角 6px | 可能不同 | ✅ 对齐 |
| 图标 | 24x24，选中蓝色 | 可能不同 | ✅ 对齐 |
