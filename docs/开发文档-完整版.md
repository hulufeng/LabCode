## 一、项目概述

LabCode 是一款集成 **Monaco 编辑器 + AI 智能体 + 内置终端 + 测试运行器** 的桌面开发工具，核心亮点是 AI 能真正动手读写代码、执行命令、运行测试，通过三种权限模式保障安全。

项目包含**三端**：

| 端 | 目录 | 说明 |
|---|---|---|
| 官方网站 | `website/` | 产品展示与下载页面 |
| 桌面客户端 | `desktop-app/` | Electron 桌面应用（核心） |
| 管理后台 | `admin/` | 用户/API/插件管理等（localStorage 本地存储） |

**品牌硬约束：**
- 品牌名：**LabCode**
- 主题：浅色白色主题，主色蓝色 `#2563eb`
- 图标：Tabler Icons 风格内联 SVG（MIT 许可，可商用）

## 六、桌面客户端架构详解

### 6.1 进程架构

```
┌─────────────────────────────────────────────────┐
│                  Electron 主进程                 │
│              main/index.js（窗口/IPC/菜单）       │
│         main/terminal.js（终端服务）             │
├─────────────────────────────────────────────────┤
│              Preload 预加载脚本                  │
│           main/preload.js（contextBridge）       │
├─────────────────────────────────────────────────┤
│              渲染进程（renderer/）               │
│  index.html（界面） + app.js（智能体引擎）       │
│  terminal.js（xterm 终端） + style.css           │
└─────────────────────────────────────────────────┘
```

- **安全配置**：`contextIsolation: true`、`nodeIntegration: false`、`sandbox: false`、`webSecurity: true`
- 渲染进程通过 `window.LabCode.*` 调用主进程能力（IPC）

### 6.2 主进程（main/index.js）

**核心职责：**
1. **窗口管理** — 无边框窗口（frame: false），宽高记忆（config.json），最大化状态保存
2. **菜单** — 原生菜单：文件/编辑/视图/帮助（4 个顶级菜单）
3. **配置存储** — `%APPDATA%\LabCode\config.json`，含 AI 配置、代理、窗口、主题、最近项目
4. **会话存储** — `%APPDATA%\LabCode\sessions\*.json`，跨会话记忆
5. **IPC 接口** — 窗口控制、配置、会话、对话框、文件读写、终端、外部链接、应用信息、代理、自动更新
6. **自动更新** — electron-updater，启动 5 秒后检查（非 dev 模式）

**数据存储位置：**

| 数据 | 路径 |
|---|---|
| 配置文件 | `%APPDATA%\LabCode\config.json` |
| 会话文件 | `%APPDATA%\LabCode\sessions\*.json` |
| 窗口状态 | config.json 的 window 字段 |

### 6.3 预加载脚本（main/preload.js）

通过 `contextBridge.exposeInMainWorld('LabCode', ...)` 暴露 API：

```javascript
window.LabCode = {
  window:   { minimize, maximize, close, isMaximized },
  config:   { get, set, save },
  sessions: { list, save, delete },
  dialog:   { openFile, openDirectory, saveFile },
  fs:       { readFile, writeFile, exists, listDir },
  shell:    { openExternal },
  app:      { getVersion, getPath, getPlatform },
  proxy:    { set },
  update:   { check, download, install },
  terminal: { create, write, resize, getBuffer, clearBuffer, kill, list, execute, onData, onExit },
  on:              (channel, callback)   // 白名单通道监听
  removeListener:  (channel, callback)
}
```

### 6.4 终端服务（main/terminal.js）

**双模式实现：**
1. **node-pty 模式**（真实伪终端）— 优先尝试加载 `node-pty`，成功则用真实 PTY
2. **降级模式**（child_process）— node-pty 不可用时，用 `child_process.spawn` + stdio 管道

**默认 Shell（Windows）：** PowerShell（`C:\Windows\System32\WindowsPowerShell\v1.0\powershell.exe`），其次 cmd

**能力：** 创建/写入/调整大小/获取缓冲区/清空/杀死/列表/一次性执行命令

### 6.5 终端管理器（renderer/js/terminal.js）

- **xterm.js 加载**：优先本地 node_modules，失败回退 CDN（jsdelivr），再失败用文本降级终端
- **终端创建**：Electron 环境走主进程 IPC；浏览器环境用 mock 终端
- **降级终端**：简单 HTML 文本终端，支持 help/clear/echo/date/pwd/ls/whoami/version 命令

### 6.8 三种权限模式

| 模式 | 行为 | 适用场景 |
|---|---|---|
| ⚡ **auto** | AI 直接执行所有操作，无需确认 | 信任 AI，快速开发 |
| 🛡 **default**（默认） | 查询自动执行；写入/删除/高风险命令弹窗确认 | 日常使用 |
| 📋 **plan** | 只读探索，先输出实施计划，确认后执行 | 大改动前规划 |

**安全机制：**
- 7 层终端命令拦截（危险模式、管道结构、链式命令、受保护路径、敏感路径、高风险命令、只读命令）
- 受保护路径：`.git/`、`.env`、`package-lock.json`、`yarn.lock`、`pnpm-lock.yaml`
- 高风险命令：`git push`、`git reset --hard`、`rm -rf`、`sudo`、`format`、`diskpart` 等
- Rule 权限引擎：支持通配符规则，可"按此修改"自动允许
- 权限决策审计：记录每次批准/拒绝（上限 5000 条）

### 新增 AI 工具步骤

在 `app.js` 的 `TOOL_DEFS` 数组添加：

```javascript
{
  name: 'my_tool',
  category: 'query',   // query(只读) / modify(修改) / execute(执行)
  description: '工具描述',
  parameters: {
    type: 'object',
    properties: {
      param1: { type: 'string', description: '参数1' }
    },
    required: ['param1']
  },
  execute: (args) => {
    // 执行逻辑
    return '执行结果';
  }
}
```

### 新增 IPC 通道步骤

1. `main/index.js` 添加：`ipcMain.handle('my:channel', (_, arg) => {...})`
2. `main/preload.js` 添加：`myModule: { myMethod: (arg) => ipcRenderer.invoke('my:channel', arg) }`

## 十二、常见问题排查

| 问题 | 解决方案 |
|---|---|
| Electron 白屏/崩溃 | 加参数启动：`--disable-gpu --no-sandbox` |
| 终端不显示 | 检查 node_modules 是否有 xterm；或看控制台 CDN 加载 |
| 按钮点了没反应 | 检查 DevTools Console 报错；确认 HTML 元素 id 与 JS 选择器一致 |
| node-pty 编译失败 | 不影响使用（自动降级），想用真实终端需装 VS Build Tools |
| 大文件读取截断 | 用 PowerShell `Get-Content -Raw` 或分块读取 |
| GitHub push 失败 | 网络不稳时用 MCP push_files 或稍后重试 |
| 重置应用数据 | 删除 `%APPDATA%\LabCode` 目录 |
