## 一、问题现象

启动客户端后底部终端显示"降级模式"，真实终端不可用：

- 日志：`[TerminalManager] xterm.js 加载失败: Error: xterm.js 加载失败`
- 日志：`[TerminalManager] 使用降级终端模式`
- 终端状态栏：`降级模式`（预期：`终端 term_x`）

## 二、诊断过程（CDP + 日志三层定位）

### 第 1 层：脚本加载路径解析错误（越出 asar）

用 CDP 检查页面实际生成的 script 标签 src：

```
file:///D:/工作/LabCode/desktop-app/dist/win-unpacked/resources/node_modules/xterm/lib/xterm.js
```

**错误点**：路径解析到了 `resources/node_modules/`（该目录不存在）。

原因：浏览器对 `<script src="相对路径">` 的解析基准是**文档 URL**（index.html 位于 `app.asar/renderer/`），
而 terminal.js 里写的 `../../node_modules/...` 按 `renderer/` 上溯两级 → 越出 app.asar 到达 `resources/`。

- 正确路径应为 `../node_modules/xterm/lib/xterm.js`（→ `app.asar/node_modules/`）
- 且原代码只尝试第一个路径后无条件 `break`，后续路径根本不会尝试

CDP fetch 验证：`fetch('../node_modules/xterm/lib/xterm.js')` → **HTTP 200，283,218 字节**，路径可达。

### 第 2 层：monaco loader 的 AMD define 拦截 UMD 全局导出

用 CDP 检查页面全局：

```json
{ "hasModule": false, "hasExports": false, "hasDefine": true, "hasTerminal": false }
```

页面加载了 monaco-editor 的 `loader.js`（requirejs），定义了全局 `define`（AMD）。
xterm 的 UMD 包装检查顺序为：

```js
if (typeof exports === 'object' && typeof module === 'object') module.exports = t();      // 不满足
else if (typeof define === 'function' && define.amd) define([], t);                        // ✅ 命中 AMD
else { for (var s in i) window[s] = i[s]; }                                                // 不执行 → window.Terminal 永不设置
```

即使脚本成功加载，`window.Terminal` 也是 undefined → 被判定为"加载失败"。

### 第 3 层：renderer 侧引用主进程变量

`renderer/js/app.js` 自动创建终端时用了 `process.cwd()`，在 contextIsolation 下 renderer 无 Node 全局 → `process is not defined`。

## 三、修复内容（4 处）

| 文件 | 修复 |
|---|---|
| `renderer/js/terminal.js` | ① xterm 路径改为 `../node_modules/xterm/lib/xterm.js`（正确解析到 app.asar 根）<br>② 加载方式改为 `fetch` + `new Function('define', code)(undefined)` 隔离执行——在函数参数作用域内屏蔽 AMD define，xterm 走全局分支挂载 `window.Terminal`，同时完全不触碰全局 `define`（不影响 monaco）<br>③ 逐个路径尝试，全部失败才回退 CDN |
| `renderer/js/app.js` | `process.cwd()` → `window.LabCode.getCwd()`（经 preload 走 IPC） |
| `main/preload.js` | 暴露 `getCwd: () => ipcRenderer.invoke('app:getCwd')` |
| `main/index.js` | 注册 `ipcMain.handle('app:getCwd', () => process.cwd())` |
