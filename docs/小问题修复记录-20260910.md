## 问题 1：文件回滚记录空值警告

### 现象
AI 调用 write_file 后，输出面板出现警告：
```
文件回滚记录失败: Cannot read properties of undefined (reading 'length')
```

### 根因
`FileChangeTracker.recordChange()` 中：
```js
const sessionTurns = this.turns.get(sessionId);  // 返回 undefined
if (!sessionTurns || sessionTurns.length === 0) this.beginTurn(sessionId);  // beginTurn 内部创建了新数组，但外层 const 仍是 undefined
const currentTurnData = sessionTurns[sessionTurns.length - 1];  // undefined.length → 报错
```
`sessionTurns` 是 `const`，`beginTurn()` 内部 `this.turns.set()` 创建的新数组不会反映到外层变量。

同时，回滚记录处提取 filePath 时只检查了 `tc.arguments?.path` 和 `?.file`，但 write_file 工具的实际参数名是 `file_path`，导致 filePath 始终为 'unknown'。

### 修复
- `recordChange`：`const` → `let`，beginTurn 后重新 `this.turns.get(sessionId)`
- filePath 提取：增加 `tc.arguments?.file_path` 兜底

### 验证
输出面板：`文件回滚记录: main.c (modify)` —— 成功，无警告 ✅

## 问题 2：无项目时 AI 写文件不写磁盘

### 现象
用户未打开项目文件夹时（`state.projectPath = null`），AI 调用 write_file 只写入内存 `state.files`，未持久化到磁盘。重启后文件丢失。

### 根因
write_file 工具的磁盘写入条件：
```js
if (isElectron && state.projectPath) {  // projectPath 为 null 时跳过
  const fullPath = state.projectPath + '/' + args.file_path;
  await FileSystem.writeFile(fullPath, args.content);
}
```

### 修复
无项目时自动创建默认项目目录并设为 projectPath：
```js
if (isElectron) {
  if (!state.projectPath) {
    const home = await window.LabCode.app.getPath('home');
    state.projectPath = home + '\\LabCodeProjects\\untitled';
    addOutputLog(`已自动创建默认项目目录: ${state.projectPath}`, 'info');
  }
  if (state.projectPath) {
    const fullPath = state.projectPath + '\\' + args.file_path;
    await FileSystem.writeFile(fullPath, args.content);
  }
}
```
主进程 `fs:writeFile` 已内置 `ensureDir(path.dirname(filePath))`，目录会自动创建。

### 验证
- 输出面板：`已自动创建默认项目目录: C:\Users\Administrator\LabCodeProjects\untitled`
- 磁盘文件：`C:\Users\Administrator\LabCodeProjects\untitled\main.c`（412 字符）✅
- 编辑器内容与磁盘一致 ✅

## 问题 3：terminal 工具是纯 mock，未真正执行 shell

### 现象
AI 调用 terminal 工具执行命令，耗时仅 1ms，返回硬编码的模拟输出（如 `(模拟执行完成，退出码 0)`），未真正运行 shell 命令。AI 回复"已成功编译"但实际未编译。

### 根因
terminal 工具的 `execute` 函数全是硬编码模拟：
```js
if (cmd.startsWith('python')) return '原始数据: [64, 34, 25...]';  // 模拟
if (cmd.startsWith('ls')) return 'src/ tests/ package.json';  // 模拟
return `$ ${cmd}\n(模拟执行完成，退出码 0)`;  // 默认模拟
```
从未调用主进程的真实命令执行通道。

### 修复
改为调用 preload 暴露的真实 IPC `window.LabCode.terminal.execute(command, cwd, timeout)`：
- 主进程 `terminal:execute` → `terminalService.executeCommand()` → `child_process.exec` 真实执行
- 返回 `{success, exitCode, stdout, stderr}`
- 输出同时写入终端面板（`state.terminal.writeln`）
- 非 Electron 环境回退为模拟

### 验证
- terminal 工具耗时：从 1ms → 25ms（真实进程启动开销）✅
- 输出面板：`工具瀑布执行: terminal 耗时 25ms` + `[成功]工具 terminal 执行完成` ✅
