硬件场景

ESP32 温湿度采集，从选型到烧录

你说一句需求，AI 自己搜板、装库、写代码、编译、烧录、盯串口。有报错它自己回读修复。

  • Arduino / ESP-IDF 工具链即装即用
  • 串口日志实时滚动，异常自动分析
  • 编译失败自动定位行号并修改
你：ESP32-S3 接个 DHT22 读温湿度
→ search_boards 找到 ESP32-S3
→ install_library DHT sensor library
→ write_file src/main.ino
→ compile ✓ 12.3s 编译过
→ serial_log T=24.6°C H=58%
软件场景

Python 脚本加功能，跑通为止

你说"给这个 CSV 去重排序"，AI 读现有代码、写新文件、跑 pytest、看结果。失败了它自己改。

  • 自动识别项目结构和测试框架
  • pytest / cargo / go test 输出结构化解析
  • 每一步都可撤销，不喜欢随时退
你：utils.py 加 CSV 去重，输出排序结果
→ read_file utils.py
→ write_file utils.py
→ run_command python -m pytest
✓ 3 passed in 0.12s
扩展场景

新工具？写个 manifest 就行

Git、Docker、数据库——任何 CLI 工具包成插件，AI 就能调用。插件从 GitHub 装，不污染主程序。

  • JSON manifest 声明工具名、参数、命令
  • 支持 CLI / HTTP / MCP / stdio
  • 插件市场浏览，一键安装
你：装个 git 插件
→ install_plugin github.com/xxx/git
✓ 3 个新工具已注册
你：提交改动打 tag
→ git_add .
→ git_commit "feat: xxx"
→ git_tag v1.1.0
