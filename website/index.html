几个常见场景

ESP32 项目

说需求，AI 帮你搭固件

"给 ESP32-S3 加个温湿度采集"——AI 自动搜板、装库、写代码、编译、烧录、盯串口。

  • Arduino / ESP-IDF 工具链内置
  • 串口日志实时监视
  • 编译报错自动回读修复
› 给 ESP32-S3 加个温湿度采集
search_boards "ESP32-S3" → 55 个板
select_board esp32:esp32:esp32s3
install_library DHT sensor library
write_file src/main.ino
compile → ✓ 编译成功 12.3s
serial_log DHT22 temp=24.6°C hum=58%
Python 脚本

描述功能，AI 写好跑通

"给这个 CSV 加个去重和排序"——AI 读现有代码、写新文件、跑测试、看结果。

  • 自动识别项目结构和测试框架
  • 跑 pytest，失败自动修
  • 全程可撤销
› 给 utils.py 加 CSV 去重功能
read_file utils.py
write_file utils.py
run_command python -m pytest
✓ 3 passed in 0.12s
插件开发

任何 CLI 工具都能接进来

写个 manifest 声明工具名、参数、执行命令，AI 就能调用。不用改 LabCode 源码。

  • JSON manifest 声明工具
  • 支持 CLI / HTTP / MCP
  • 插件从 GitHub 安装
› 装个 git 插件
install_plugin github.com/xxx/git-plugin
✓ 安装完成，3 个新工具可用
› 提交所有改动并打 tag
git_add .
git_commit "feat: xxx"
git_tag v1.1.0
