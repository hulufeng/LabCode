如何安装插件

  1. 打开 LabCode，进入「设置」（顶部工具栏 ⚙ 或 AI 面板设置）。
  2. 选择左侧「插件」标签页。
  3. 在「市场 · 官方插件」区点击目标插件的「安装」，或点「从文件夹 / ZIP 安装」加载本地插件包。
  4. 安装完成后，插件贡献的能力 / 命令 / 视图 / 项目类型自动接入：工具栏与侧栏出现对应按钮与插件入口，AI 智能体获得插件工具与技能（输入框输入 / 查看技能）。
