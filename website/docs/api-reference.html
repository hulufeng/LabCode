接口参考

官网后端 server.mjs 是零依赖 Node ESM 服务（默认端口 8788），经 nginx 反代到 /codelab/api/。以下为公开接口；管理后台在 /admin/（需登录）。

Base URL：浏览器侧访问 https://bluebubai.work/codelab/api；本地直连后端为 http://localhost:8788/api。

插件市场

GET/api/plugins

返回插件市场列表。可选查询 ?category=&q= 过滤。

[
  {
    "id": "arduino-cli-toolchain",
    "name": "Arduino 工具链",
    "version": "1.2.0",
    "category": "toolchain",
    "summary": "编译 / 烧录 Arduino 工程",
    "downloads": 1820
  }
]

内容块

GET/api/content?key=homepage_banner

按 key 取可编辑的内容块（首页横幅、特性等）。

{ "key": "homepage_banner", "title": "...", "body": "..." }

版本

GET/api/version

返回当前客户端最新版本与下载地址，供更新检测使用。

{ "version": "1.4.2", "notes": "...", "url": "https://.../LabCode-Setup.exe" }

联系表单

POST/api/contact

提交联系 / 反馈表单。Body 为 JSON：

{ "name": "张三", "email": "a@b.com", "message": "..." }

成功返回 200 { "ok": true }。

下载计数

GET/api/downloads?file=LabCode-Setup.exe

返回指定安装包的累计下载次数。

{ "file": "LabCode-Setup.exe", "count": 5821 }

管理后台

GET/admin/

管理后台入口，需管理员登录（邮箱 + 密码）。登录态用 token 校验，跨重启稳定（密码盐已固定为字面量，详见 更新日志）。

三通道 AI 网关

AI 调用支持 function calling，三通道由配置切换，不在本 REST 接口范畴：

  • 本地 llama：本机部署模型，数据完全不出机
  • BYOK：填入自有 API Key 直连你的模型服务
  • 官方登录 + 积分：注册送积分，免费起步
