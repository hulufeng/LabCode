Arduino / ESP32 开发

LabCode 内置了 Arduino CLI 工具链，AI 可以帮你完成从选板到烧录的全流程。

第一次用

  • 把开发板插 USB，装驱动（CH340 / CP2102 等，Windows 一般自动装）
  • 新建项目时选"Arduino 项目"，会生成 src/main.ino
  • 在 AI 对话里说你要做什么，比如"用 ESP32-S3 接 DHT22 读温湿度"

AI 会做什么

  • search_boards：按关键字搜开发板，列出 FQBN
  • select_board：选中板子
  • install_library：装需要的库（DHT、WiFi、传感器等）
  • write_file：写 .ino 代码
  • compile：编译，失败自动读报错改代码
  • upload：烧录到板子
  • serial_log_open / serial_log：开串口监视，实时看输出

常用命令示例

# 编译当前项目
arduino-cli compile --fqbn esp32:esp32:esp32s3 .

# 烧录到 COM3
arduino-cli upload -p COM3 --fqbn esp32:esp32:esp32s3 .

# 看串口
arduino-cli monitor -p COM3 -c baud=115200

这些命令你不需要自己敲——AI 会自动调用。你只需要用自然语言描述需求。

国内下载慢？LabCode 默认配了 jihulab 镜像源。如果还慢，可以在 设置 → 工具链 → 镜像源 里切换。

常见问题

编译报 bootloader 缺失

ESP32 平台包安装不完整。在 AI 对话里说"重新装一下 esp32:esp32 平台"，它会自动卸载重装。

串口被占用

关掉 Arduino IDE 或其他串口监视器，再让 AI 重试。

ESP-IDF

目前只支持 Arduino 框架。ESP-IDF 原生支持在计划中。
