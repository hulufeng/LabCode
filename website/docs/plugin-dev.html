插件开发

插件就是一个文件夹，里面有个 plugin.json 清单。LabCode 读这个清单就知道要给 AI 注册哪些工具。

最小插件

my-plugin/
├── plugin.json
└── README.md

plugin.json 示例

{
  "id": "my-git-tools",
  "name": "Git 小工具",
  "version": "0.1.0",
  "tools": [
    {
      "name": "git_status",
      "description": "查看 git 工作区状态",
      "command": "git status --short"
    },
    {
      "name": "git_commit",
      "description": "提交当前改动",
      "args": [
        {"name": "message", "type": "string", "description": "提交信息"}
      ],
      "command": "git commit -m {{message}}"
    }
  ]
}

安装插件

  • 把插件文件夹丢到 %APPDATA%\LabCode\plugins\ 下
  • 或在 AI 对话里说"装这个插件：<GitHub 地址>"，它会自动下载
  • 重启或在插件面板点"刷新"

通道类型

目前支持：

  • cli：执行命令行（最常用）
  • http：调 HTTP 接口
  • mcp：接 MCP 服务器
