快速开始

5 分钟从安装到让 AI 帮你跑通第一个脚本。

LabCode 是一个跑在你本机的 AI 编程桌面端。它和聊天机器人最大的区别是：它真的会读你的项目、改你的文件、跑命令看结果。不是给你贴一段代码让你自己复制粘贴。

1. 下载并安装

到 官网首页 点"免费下载"，拿到 LabCode-Setup-1.0.0.exe（约 146 MB）。

  • 系统要求：Windows 10 / 11（64 位）
  • 双击 exe，一路"下一步"即可，不需要先装 Python / Node / 编译器
  • 安装完桌面会出现 LabCode 图标

2. 打开 AI 对话

启动后，右侧就是 AI 对话面板。首次启动它会自动加载内置的本地模型（Qwen3.5-9B，Vulkan 加速），模型加载需要几秒钟。

你不需要做任何配置——API Key、模型路径、工具链路径都已经打包好了。

3. 让 AI 帮你写第一个脚本

在输入框里用大白话描述需求，比如：

帮我写一个 Python 脚本，读取同目录的 data.csv，
按"姓名"列去重，按"日期"排序，输出到 out.csv

AI 会自己做这几件事：

  • 在左侧文件树里新建项目目录
  • 写 main.py 和示例 data.csv
  • 在底部终端里跑 python main.py
  • 看到报错（如果有）会自己读、自己改、再跑

整个过程你只需要看着，每一步它会在对话里告诉你它在干嘛。改文件前它会弹确认，你点头才执行。

4. 跑通后看看结果

切到底部"终端"标签，可以看到真实输出。切到左侧文件树，打开 out.csv 验证结果。

小提示：每一步 AI 做的文件修改都可以撤销。如果它改得不满意，直接说"撤销刚才的修改"或者按 Ctrl+Z。

5. 下一步

  • 想做硬件？去看 Arduino / ESP32 开发，从选板到烧录一条龙
  • 想知道 AI 都有哪些工具？去看 AI 助手使用
  • 想自己写插件？去看 插件开发

嵌入式 5 分钟（Arduino）

如果你有 ESP32 开发板，流程也很简单：

  • 新建项目时选"Arduino 项目"
  • 把板子插上 USB，AI 会自动识别串口号
  • 跟 AI 说"接 DHT22 读温湿度，板号选 ESP32-S3"
  • 它自己搜板、装库、写代码、编译、烧录、开串口监视

完整参数和故障排查见 Arduino / ESP32 开发。
