快速开始

5 分钟上手 LabCode —— 从下载安装到让 AI 智能体帮你写出第一个可运行的程序。

LabCode 是一款通用软件开发智能体：内置 AI 智能体 + 现代编辑器 + 终端，读写代码、执行命令、运行测试全在一个桌面应用内完成。嵌入式开发（Arduino / ESP-IDF / STM32）以工具链插件形式开箱即用。

1. 下载并安装

1

下载安装包

前往下载页点击「下载安装包」，获取 LabCode-Setup 安装程序。

  • 系统要求：Windows 10 / 11（64 位）
  • 安装包为 NSIS 安装程序，双击运行，一路「下一步」即可
  • 安装完成后，桌面会自动创建 LabCode 快捷方式

2. 创建你的第一个工程

2

新建工程

  • 点击工具栏的「新建文件」，或菜单 文件 → 新建文件
  • 选择工程类型：Python / Node.js / C++ / Rust / 通用（或已安装插件提供的类型，如 Arduino）
  • 输入工程名称，软件会自动生成对应的工程结构与入口文件

3. 让 AI 帮你写代码

3

用自然语言描述需求

在右侧 AI 面板中，用自然语言描述你的需求，例如：

给这个 Python 项目加一个用户登录功能，密码用 sha256 哈希存储

AI 会自动：

  • 读取你的工程结构
  • 生成完整代码并写入文件（如 auth.py）
  • 运行测试或命令验证能否通过
内置免费模型：LabCode 内置智谱 GLM-4.7-Flash 免费模型，注册即送积分，零成本起步；也支持配置自有 API Key（BYOK）直连你的模型服务。

4. 运行测试

4

验证代码

  • 让 AI 运行 pytest（Python）/ npm test（Node）/ go test / cargo test——内置测试运行器自动识别项目框架并解析结果
  • 测试失败时，AI 会根据失败分类（断言 / 编译 / 超时）自动修复并重跑
  • 也可以在底部面板的内置终端里手动执行任意命令

5. 验证结果

5

运行你的程序

程序跑通后，你可以直接在内置终端里运行它（如 python main.py），看到真实输出。

恭喜！你已完成第一次完整的 LabCode 开发流程。接下来可以阅读 插件开发指南 了解插件体系。

嵌入式快速开始（Arduino）

LabCode 完整支持 Arduino，由 arduino-cli-toolchain 插件提供：

  • 启用工具链：安装插件后打开一个 Arduino 项目时按提示启用，或到「设置 → 插件」手动启用
  • 新建项目：新建 → 选择「Arduino 项目」，生成 xxx.ino
  • 选板选口：左侧「设备」面板选择开发板（FQBN）与串口端口
  • 编译 / 上传：工具栏「上传」一键编译烧录
  • 串口：「串口监视器」独立窗口实时查看输出、发送命令

ESP-IDF 快速开始

由 esp-idf-toolchain 插件提供（开发中）：

  • 检测工具链：打开插件「目标与工具链」视图，自动检测本机已装 ESP-IDF；未安装可一键下载官方安装器
  • 新建项目：新建 → 选择「ESP-IDF 项目」（默认目标 esp32）
  • 选目标芯片：左侧「设备」面板选中即自动 set_target
  • 编译 / 配置 / 烧录：工具栏编译；「配置」视图图形化改 Kconfig；「烧录」写板

STM32 快速开始

由 stm32-cube-toolchain 插件提供（开发中）：

  • 打开已有 CubeMX 工程：检测本机已装 STM32CubeCLT → 文件 → 打开 CubeMX 生成的 CMake 工程 → 编译 / 烧录（ST-Link SWD）
  • 新建裸机脚手架：新建 → 选择「STM32 裸机 F103C8T6（蓝药丸）」等，直接编译 / 烧录点亮板载 LED
