AI 助手使用

怎么跟它说话

用大白话就行，不需要写提示词。比如：

  • "把这个 CSV 按日期去重排序"
  • "ESP32 接个 OLED 显示温度"
  • "这个报错帮我看看为啥"
  • "给项目加个 README"

三种权限模式

  • plan：AI 只出方案，不动手。适合先看思路。
  • default（默认）：改文件、跑命令前弹确认，你点头才执行。
  • auto：全自动，AI 自己决定要不要做。适合信任它之后用。

它能调用的工具

  • read_file / write_file：读写项目文件
  • run_command：跑 shell 命令
  • web_search / web_fetch：联网查资料
  • ask_user：拿不准时问你（带选项）
  • create_project：新建项目
  • Arduino 全套工具（见 Arduino 章节）
  • 插件注册的工具

对话记录

每次对话自动保存，左侧边栏可以切换历史会话。不会丢。

本地模型 vs 云端

默认用内置的 Qwen3.5-9B 本地模型，代码不出本机。如果想接更强的云端模型（DeepSeek、Qwen-Max 等），在设置里填 OpenAI 兼容的 API Key 和端点即可。
