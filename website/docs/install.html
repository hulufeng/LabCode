下载与安装

LabCode 目前只提供 Windows 版本，macOS 和 Linux 在计划中。

系统要求

  • Windows 10 或 11（64 位）
  • 硬盘剩余空间 ≥ 2 GB（含本地模型）
  • 建议 8 GB 以上内存
  • NVIDIA 显卡可选（有 Vulkan 支持可加速本地模型，没有也能跑 CPU 模式）

下载

从官网 下载页 获取 LabCode-Setup-x.x.x.exe。文件约 146 MB。

安装

  • 双击 exe，选安装路径（默认 %LOCALAPPDATA%\Programs\LabCode）
  • 不需要管理员权限，不需要装 Python / Node / Arduino IDE
  • 安装包自带了运行时和本地模型，装完即用
首次启动：AI 模型加载需要 3-10 秒，右下角会有进度提示。模型文件在 %APPDATA%\LabCode\models\，如果想换模型可以替换这个目录下的 gguf 文件。

自动更新

软件启动后 5 秒会自动检查更新，运行中每小时检查一次。发现新版本会在后台静默下载，下载完自动重启安装。你不需要手动操作。

卸载

Windows 设置 → 应用 → LabCode → 卸载。用户数据在 %APPDATA%\LabCode\，卸载不会自动删除，想清干净手动删这个目录即可。
