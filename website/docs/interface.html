界面介绍

LabCode 窗口分三块：左侧文件树、中间代码编辑器、右侧 AI 对话。

左侧：文件树

显示当前项目的目录结构。点文件在中间打开。AI 改文件时这里会实时刷新。

中间：编辑器

基于 Monaco（VS Code 同款内核），支持多语言高亮、多标签、括号匹配。AI 改文件时会标注改动位置。

右侧：AI 对话

你和 AI 聊天的地方。AI 调用工具时会展开显示工具名、参数和结果。改文件前弹确认卡片，点"允许"才执行。

底部：面板

可以切换：

  • 终端：交互式 shell，AI 也在这里跑命令
  • 输出：编译 / 测试输出
  • 串口：Arduino 串口监视器（用 Arduino 项目时出现）
