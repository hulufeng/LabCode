常见问题

AI 回复很慢怎么办？

本地 9B 模型在没有独立显卡的机器上会比较慢。有 NVIDIA 显卡会自动用 Vulkan 加速。或者在设置里接云端 API。

AI 改了我不想让它改的文件怎么办？

切到 default 模式（默认就是），每次改文件前它都会弹确认卡片。点"拒绝"就不会改。

数据安全吗？

用本地模型时代码完全在你电脑上，不会上传。接云端 API 时，你当前对话的代码片段会发给你配置的那个云端服务。

怎么更新？

自动更新，不用管。启动和运行中都会自动检查。

支持哪些编程语言？

编辑器层面支持所有 Monaco 支持的语言（Python、JS/TS、C/C++、Rust、Go、Java、Arduino 等）。AI 能帮你写什么取决于模型能力。

ESP32 编译报 bootloader 缺失

在 AI 对话里说"重装 esp32 平台"即可。
